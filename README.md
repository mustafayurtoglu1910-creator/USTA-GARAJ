# USTA GARAJ

Mobil uyumlu, tarayıcıda çalışan araç bakım ve arıza tespit oyunu prototipi.

## İlk hedef
- İlk araç: Fiat Egea 1.4 benzinli, 2022 sedan.
- Oyuncu, araç parçalarını seçerek kontrol ve bakım görevlerini tamamlar.
- Sonraki geliştirme aşaması: aynı garajda iki oyunculu çevrimiçi oyun.

## Çalıştırma
Şimdilik prototip tek sayfalı web uygulaması olarak hazırlanacaktır. `index.html` dosyası tarayıcıda açılarak çalıştırılabilir.

## Geliştirme notu
Parça yerleşimleri ilk prototipte şematiktir; gerçek araç yerleşimi ve teknik değerler doğrulanmış servis dokümanlarıyla ayrıca kontrol edilmeden kesin teknik bilgi olarak kullanılmamalıdır.
